# 版式说明

版式只在 [styles.typ](styles.typ) 里维护；内容是 [print.py](../print.py) 生成的
`build/book.typ`，不手改。改版式前先读这份。

## 目标

- A4 单面，左边装订，黑白打印优先。
- 说明做成“字段卡片”，代码做成“代码卡片”；先看字段，再抄代码。
- 长板可以跨页，但页眉要能看出当前小节；不允许只有一两行的孤页。

## 变量

| 变量 | 值 | 用途 |
|---|---|---|
| `ink` | `#14181B` | 标题、正文重色 |
| `text-ink` | `#2A3136` | 正文 |
| `accent` | `#1D4E5F` | 编号、字段标签、复杂度 |
| `accent-soft` | `#E9F0F2` | 复杂度底色 |
| `muted` / `faint` / `hint` | 灰阶 | 页眉、页码、行号 |
| `rule` | `#D9DEE1` | 细线 |
| `code-fill` / `code-rule` | `#F7F8F8` / `#E4E8EA` | 代码卡片 |
| `sans-font` | Inter → Noto Sans CJK SC | 正文、标题 |
| `mono-font` | Noto Sans Mono → Noto Sans Mono CJK SC | 代码、例子、行号 |
| `body-size` / `field-size` / `code-size` | 9.7 / 9.2 / 7.8pt | 三档字号 |

改配色/字号先改这里，不要在函数里写死。

## 结构

- `fields(rows)`：两列网格，标签宽 4.3em；行数据是 `("标签", 内容)`。
- `example(body)`：等宽 + 左侧细线，用来放“例”和“用法”。
- `code(body)`：代码卡片的外框、底色、圆角、留白；codly 只管行号和语法色。
- `cmplx(value)`：把复杂度挂到下一个二级标题右端。
- `book(...)`：页面、封面、目录、页眉页脚、标题样式。

## 页面

- 正文边距：左 20mm、右 17mm、上 17mm、下 17mm；双面时内侧 20/外侧 16mm。
- 章不单独占整页：页首一条紧凑的章标题带，下面直接跟第一节。
- 目录用单栏全宽，一页放下；条目 8.6pt，章 9.8pt。
- 页眉左边书名，右边**当前小节**；长板跨页时靠它认位置。
- 页码在下方外侧。

## 长板

`print.py` 会估算“标题 + 字段 + 代码”的高度：

- 放得下：整节包在 `#block(breakable: false)` 里，不拆。
- 放不下：先翻页，标题和字段一组，代码卡片允许分页。
- 当前只有欧拉路（147 行）会占两页；第二页页眉仍是“欧拉路（Hierholzer）”。

新增长板如果只多出几行，先压掉代码空行或拆成两个逻辑小节；
不要为了压页单独缩小某一节字号，字号一乱整本就不齐。

## 改版式流程

1. 只改 `styles.typ`（必要时 `theme.tmTheme`）。
2. `python3 print.py --check`，再 `python3 print.py`。
3. 看四类页：封面、目录、章首页、长板跨页。
4. 版式改动单独提交，提交信息写“版式”。
